# Efectos de Sonido - Trivia Colombia

Este directorio forma parte de la arquitectura del proyecto para recursos auditivos:
- Efectos de acierto
- Efectos de error
- Tic-tac del temporizador
- Sonido de comodín
- Fanfarria de victoria

Los sonidos son reproducidos y sintetizados directamente en el navegador a través de **Web Audio API** (`js/sonidos.js`), garantizando cero latencia, portabilidad total y compatibilidad offline sin fallos de carga en Vercel o en modo local.
